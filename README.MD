# 🔥 Fire Burger House

> Cardápio digital moderno para hamburgueria — desenvolvido com HTML, CSS e JavaScript puro.

Sistema web que permite aos clientes visualizar produtos, adicionar itens ao carrinho e realizar pedidos de forma simples e intuitiva. O projeto também conta com uma estrutura de painel administrativo para gerenciamento interno.

---

## 🚀 Demonstração

| Página | Descrição |
|---|---|
| `index.html` | Tela de login do painel admin |
| `pages/Home.html` | Página inicial do cardápio |
| `pages/Cardapio.html` | Listagem de produtos por categoria |
| `pages/promocoes.html` | Promoções em destaque |
| `pages/Admin/Dashboard.html` | Painel administrativo |
| `pages/Admin/Pedidos.html` | Gerenciamento de pedidos |
| `pages/Admin/Relatorio.html` | Relatórios e estatísticas |
| `pages/Admin/Configurações.html` | Configurações do sistema |

---

## 🍔 Funcionalidades

- 📋 Cardápio com categorias (Hambúrgueres, Batatas, Bebidas, Sobremesas)
- 🔥 Página de promoções
- 🛒 Carrinho de pedidos com cálculo automático do total
- 🧭 Navegação entre páginas
- 🎨 Interface moderna e responsiva
- ⚙️ Painel administrativo com Dashboard, Pedidos e Relatórios

---

## 🖥️ Tecnologias Utilizadas

- **HTML5** — Estrutura das páginas
- **CSS3** — Estilização e layout responsivo
- **JavaScript** — Lógica do carrinho e interações

## 🛒 Como Usar

1. Acesse a página **Home** para ver o cardápio
2. Navegue pelas **categorias** de produtos
3. Adicione itens ao **carrinho**
4. Veja o **total calculado automaticamente**

Para o painel admin, acesse `index.html` e faça login.

## ⚙️ Painel Administrativo
